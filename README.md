# KICKORA
Kickora es una tienda online de zapatillas para niños y niñas.  
El sitio está desarrollado con **HTML, CSS y BOOTSTRAP**, y presenta una interfaz moderna y adaptable.

## 🌐 Deploy

Podés ver el proyecto online acá:

🔗 [Ver Kickora en vivo](https://kickora.netlify.app/)

## 🧠 Aprendizajes aplicados

Durante el desarrollo de Kickora se aplicaron los siguientes conocimientos:

- Estructura semántica con HTML5.
- Estilización con CSS3.
- Uso de Bootstrap para diseño responsive.
- Implementación de componentes como navbar, carrusel, cards, formularios y footer.
- Organización de archivos y carpetas del proyecto.
- Control de versiones con Git.
- Trabajo con ramas, commits y pull requests en GitHub.
- Diseño de una interfaz adaptable a distintos dispositivos.

## 🧩 Metodología de trabajo: Scrum

Para la organización del proyecto se utilizó la metodología **Scrum**, dividiendo el desarrollo en tareas y etapas de trabajo. Esto permitió que cada integrante del equipo pudiera enfocarse en una parte específica del sitio, manteniendo una mejor organización y seguimiento del avance.

Durante el desarrollo se trabajó con una planificación por tareas, asignación de roles y revisión de avances. Además, se utilizó Git y GitHub para gestionar las ramas, commits y la integración de cambios al proyecto principal.
